# Privacy Policy for WebSculpt

WebSculpt is a browser automation CLI and a set of Agent skills that runs entirely on the user's local machine.

## What we collect

We do **not** collect, transmit, or store any personal data or usage information. The WebSculpt plugin, the WebSculpt CLI, and the associated skills do not connect to any remote server operated by the publisher.

## Local data

- The plugin connects to the user's own local Chrome browser instance via the Chrome DevTools Protocol (CDP).
- Cookies, login sessions, and browsing data remain on the user's machine.
- Distilled commands and command libraries are stored locally, typically under `~/.websculpt` or the equivalent user directory.

## Third-party websites

When using WebSculpt to interact with third-party websites, users are responsible for complying with the privacy policies and Terms of Service of those websites.

## Contact

For questions about this privacy policy, please open an issue at https://github.com/bqw1013/WebSculpt/issues.
